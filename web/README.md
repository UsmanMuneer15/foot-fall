# FOOTFALL GLOBAL LLC Website

Premium Next.js website for FOOTFALL GLOBAL LLC — experiential engagement and audience attraction.

Built from the final developer script and homepage design reference:

- Deep luxury green + metallic gold identity
- Homepage matching the approved layout
- Full responsive navigation and pages: Home, About, Experiences, Technology, Case Studies, News, Contact

## Run locally

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
